# Проблема глобального потепления
## В этом проекте я создал ТГ бота, который рассказывает пользователю всё, что он попросит, про глобальное потепление! Проект выполнен Топоровым Русланом.
Пока я создавал этот проект, у меня была цель: создать что-то, что может помочь в решении такой проблемы, как глобальное потепление.
## Подключив этот код к ТГ боту пользователь может:
- Узнать краткую или полную информацию о проблеме.
- Узнать, что может случиться, если продолжить бездействовать.
- Узнать, каким образом можно помочь в предотвращении того, что может последовать за проблемой.
## Для применения этого кода вам потребуется вставить токен своего бота в указанное место, а также вам может понадобиться установить следующие библиотеки:
- pip install pyTelegramBotAPI
- pip install os
